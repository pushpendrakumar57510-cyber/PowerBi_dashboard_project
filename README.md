# PowerBi_dashboard_project
# 📊 Global Superstore Sales & Profit Analysis

> 🚀 An interactive Power BI dashboard designed to analyze sales, revenue, profit, cost, orders, customers, discounts, and business performance across global markets.

---

## 🔎 Project Overview

This project transforms Global Superstore data into an interactive **Power BI Business Intelligence Dashboard**.

The dashboard allows users to explore business performance using interactive filters such as **Market, Category, Sub-Category, and Year**.

## 📊 Interactive Analysis

### 📈 Sales Trend

Sales increased across the displayed years:

**2012 → 2013 → 2014 → 2015**

The dashboard makes it easy to explore how sales performance changes over time.

### 🛍️ Category Analysis

Sales can be compared across:

- 💻 Technology
- 🪑 Furniture
- 📁 Office Supplies

### 🌍 Market Analysis

Profit can be analyzed across different global markets:

- Asia Pacific
- Europe
- LATAM
- Africa
- USCA

---

## 🎛️ Interactive Filters

Users can dynamically filter the dashboard by:

`Market` → `Category` → `Sub-Category` → `Year`

All major KPIs and visualizations update according to the selected filters.
